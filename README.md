# Домашнее задание: *Проект интернет-магазина*"

## Описание функционала:

- есть приложения catalog, blogs и users
- в приложении catalog есть две модели: Category и Product
- в приложении blogs модель Blogs
- добавлена возможность администрировать сущности базы данных через супер пользователя
- реализована команда добавления тестовых данных из фикстур в базу данных
- созданы страницы: "home", "contacts", "base", "products__", "blogs__"
- все созданные страницы связаны между собой ссылками
- на странице "contacts" можно отправить POST-запрос
- добавлена валидация для модели Product
- формы продукта стилизованы
- в приложении users модель создания пользователя User
- можно регистрироваться, входить и выходить из личного кабинета (личный кабинет в разработке)
- отправляется письмо подтверждения почты
- создавать, изменять и удалять продукты может только создатель или суперюзер
- создавать, изменять и удалять категории может только персонал
- записи в блоге может вести любой авторизованный пользователь, удалять и редактировать только создатель
- добавлена кастомная группа пользователей-модераторов
- добавлены кастомные команды на создание суперюзера и модератора
- добавлено кэширование для списка продуктов и каждого продукта отдельно
- создана сервисная функция, возвращающая список продуктов в указанной категории


## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/Onny-ch/home_django_project.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
3. Сделайте копию .env.sample, заполните его своими данными, переименовав в .env
```
В settings добавьте настройки своего почтового сервиса (по умолчанию - Яндекс) 
```

## Использование:

На данный момент функционал можно потестировать запустив сервер командой "python manage.py runserver";

Загрузить в базу данных тестовые данные командой "python manage.py add_category_and_product";

А так же создать супер пользователя, пройти по ссылке "http://127.0.0.1:8000/admin/" и работать с данными вручную.

Можно создать суперюзера командой "python manage.py csu"

Можно создать модератора командой "python manage.py cmu"
